# iTerm2 (portable dotfiles)

Versioned here:

- `colors/*.itermcolors` — Catppuccin schemes (bundled in-repo)

**Not** in this repo (machine-local):

- `AppSupport/` — dynamic app state
- `sockets/` — secrets and IPC

Import colors: iTerm2 → Settings → Profiles → Colors → Color Presets → Import.

Dynamic profiles and preferences can be added later as static JSON once sanitized.
